# 💻 Windows Setup Guide for RISC-V Pipeline Simulation

To run the Icarus Verilog simulations and tests on a Windows laptop, you need a few tools installed. Here is the exact step-by-step setup.

### 1. Install Git Bash (Required for running `.sh` scripts)
The tests use bash scripts (`run_all_tests.sh`). Windows Command Prompt can't run these directly, so you need Git Bash.
1. Download Git for Windows: [https://git-scm.com/download/win](https://git-scm.com/download/win)
2. Run the installer and click "Next" through all the default options.
3. Once installed, you can right-click in any folder and select **"Open Git Bash here"** to get a Linux-like terminal.

### 2. Install Python 3 (Required for `gen_hex.py`)
The pipeline uses a custom Python script to generate the memory hex files for the tests.
1. Download Python: [https://www.python.org/downloads/windows/](https://www.python.org/downloads/windows/)
2. Run the installer.
3. ⚠️ **CRITICAL STEP**: On the very first screen of the installer, check the box that says **"Add Python to PATH"** before clicking Install.

### 3. Install Icarus Verilog & GTKWave (Required for Simulation)
This is the compiler (`iverilog`) and simulator (`vvp`) that actually runs the hardware Verilog code.
1. Download the latest Windows installer from here: [https://bleyer.org/icarus/](https://bleyer.org/icarus/)
   - Look for the latest stable build (e.g., `iverilog-v12-20220611-x64_setup.exe`).
2. Run the installer.
3. ⚠️ **CRITICAL STEP**: During installation, make sure you check the boxes for:
   - **"Add executable folder(s) to the user PATH"**
   - **"Install GTKWave"** (This lets you view the waveforms if you want to debug).

### 4. Verify the Installation
Open **Git Bash** and type these commands to make sure everything is installed and detected:

```bash
python --version
# Should say Python 3.x.x

iverilog -V
# Should print the Icarus Verilog version info
```

## 🚀 How to Run the Tests

Once everything is installed, it is extremely simple to run the test suite:

1. Open the project folder in File Explorer.
2. Go into the `tests` folder.
3. Right-click anywhere in the blank space and select **"Open Git Bash here"**.
4. Run the bash scripts:

```bash
# Run all standard pipeline tests
bash run_all_tests.sh

# Run the cache stress tests
bash run_cache_stress_tests.sh
```

*(Optional) If you ever want to view the waveforms generated by a test:*
```bash
gtkwave pipeline_waveforms.vcd
```
